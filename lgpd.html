Política de Privacidade e LGPD

1. Introdução

Esta Política de Privacidade descreve como o DevBooks coleta, usa e protege suas informações pessoais em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

2. Dados Coletados

O DevBooks coleta apenas dados necessários para o funcionamento da plataforma educacional:

  • Dados de navegação: Informações sobre páginas visitadas e quizzes realizados (armazenados localmente no seu navegador)
  • Preferências do usuário: Configurações de tema (claro/escuro) armazenadas localmente
  • Dados de interação: Código digitado nos editores e resultados de simuladores (não são enviados para servidores externos)

Não coletamos dados pessoais identificáveis como nome, e-mail ou endereço IP.

3. Finalidade do Tratamento

Os dados são tratados exclusivamente para:

  • Fornecer uma experiência educacional personalizada
  • Rastrear o progresso do usuário no aprendizado
  • Manter preferências do usuário (como tema)
  • Melhorar a funcionalidade da plataforma

4. Compartilhamento de Dados

Não compartilhamos seus dados com terceiros. Todas as informações são armazenadas localmente no seu navegador e não são transmitidas para nossos servidores ou qualquer serviço externo, exceto quando você interage com APIs públicas (como GitHub ou Stack Overflow) através dos botões específicos no site.

5. Seus Direitos (LGPD)

De acordo com a LGPD, você tem os seguintes direitos:

  • Confirmação: Solicitar confirmação sobre a existência de tratamento de dados
  • Acesso: Acessar seus dados pessoais
  • Correção: Solicitar correção de dados incompletos, inexatos ou desatualizados
  • Anonimização: Solicitar anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade: Solicitar portabilidade dos dados
  • Eliminação: Solicitar eliminação dos dados tratados com consentimento
  • Revogação: Revogar consentimento para tratamento de dados

6. Segurança

Como os dados são armazenados localmente no seu navegador, a segurança depende das configurações do seu dispositivo. Recomendamos manter seu navegador atualizado e usar senhas fortes.

7. Cookies e Tecnologias Similares

O site usa localStorage do navegador para armazenar preferências e progresso. Não utilizamos cookies tradicionais ou rastreamento de terceiros.

8. Menores de Idade

O site é destinado a maiores de 13 anos. Não coletamos intencionalmente dados de menores de idade.

9. Alterações nesta Política

Podemos atualizar esta política periodicamente. As alterações serão publicadas nesta página com data de atualização.
