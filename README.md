# DevBooks - Plataforma de Aprendizado de Programação

![DevBooks Logo](https://img.shields.io/badge/DevBooks-Learning%20Platform-blue?style=for-the-badge&logo=book)

Uma plataforma educacional interativa e gratuita para aprender linguagens de programação, incluindo C, Bash/Linux e CMD/PowerShell, desde conceitos básicos até níveis avançados de especialização.

## 📚 Sobre o Projeto

DevBooks é uma plataforma completa de aprendizado que oferece:
- **Conteúdo Progressivo**: Do básico ao avançado em múltiplos níveis
- **Interatividade**: Editores de código, simuladores e quizzes
- **Gamificação**: Sistema de progresso e conquistas
- **Integração com APIs**: Exemplos reais do GitHub e discussões no Stack Overflow
- **Design Responsivo**: Interface moderna com modo escuro
- **Múltiplas Linguagens**: C, Bash, CMD, PowerShell

## 🚀 Funcionalidades

### 📖 Módulos de Aprendizado
1. **Fundamentos de C** - Sintaxe básica, variáveis, estruturas de controle
2. **Sistemas Operacionais** - Interação com SO, processos, threads
3. **C++ e Orientação a Objetos** - Evolução para C++, classes, herança
4. **Algoritmos e Estruturas de Dados** - Complexidade, algoritmos eficientes
5. **Produção e Desenvolvimento** - Boas práticas, versionamento, deployment
6. **Especialização e Carreira** - Áreas avançadas, certificações, networking
7. **Nível Mestre** - Tópicos avançados, pesquisa, contribuição open source
8. **Bônus: Algoritmos Avançados** - Técnicas especiais e otimizações
9. **Nove: Desenvolvimento Web** - Integração C com web
10. **Décimo: IA e Machine Learning** - Aplicações avançadas
11. **Mestre em Linux** - Sistema operacional universal, scripts Bash
12. **CMD vs PowerShell** - Shells do Windows, automação

### 🛠️ Ferramentas Interativas
- **Editor de Código C**: Com realce de sintaxe, simulação printf
- **Editor Bash**: Scripts Linux com execução simulada ou remota
- **Editor CMD/PowerShell**: Comandos Windows
- **Simuladores**: printf, bash commands, execução remota via API
- **Quizzes Avaliativos**: Teste seu conhecimento em cada módulo
- **Sistema de Progresso**: Acompanhe seu avanço
- **Integrações**: GitHub API, Stack Overflow, Piston API para execução

### 🎨 Interface
- Design moderno com Tailwind CSS
- Modo escuro/claro
- Totalmente responsivo
- Navegação intuitiva

## 🏗️ Tecnologias Utilizadas

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
- **Editores**: Ace Editor para edição de código (C, Bash, PowerShell)
- **APIs**: GitHub API, Stack Overflow API, Piston API (execução remota)
- **Armazenamento**: localStorage para progresso e preferências
- **Responsividade**: Mobile-first design
- **Linters**: SonarQube para qualidade de código

## 🚀 Como Usar

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/carlospiquet2023/devbooks.git
   cd devbooks
   ```

2. **Abra no navegador**:
   - Abra o arquivo `index.html` em seu navegador
   - Ou use um servidor local (recomendado para melhor experiência)

3. **Comece aprendendo**:
   - Navegue pelas páginas usando os cards na página inicial
   - Leia o conteúdo, pratique nos editores
   - Faça os quizzes para testar seu conhecimento
   - Acompanhe seu progresso no dashboard

## 🎯 Objetivos de Aprendizado

## 🔧 Correções e Melhorias Recentes

### v1.1.0 - Outubro 2025
- ✅ **Novo Módulo Linux**: Editor interativo Bash com simulação local e execução remota
- ✅ **Novo Módulo CMD/PowerShell**: Comparação e prática com shells Windows
- ✅ **Correções de Sintaxe**: Escape de caracteres especiais em exemplos de código
- ✅ **Melhorias no Editor**: Suporte robusto a clipboard, fallbacks para navegadores antigos
- ✅ **Simuladores Aprimorados**: Mais comandos simulados (ls, pwd, whoami, date, etc.)
- ✅ **Quizzes Expandidos**: 10 perguntas por módulo, correção de ordem de inicialização
- ✅ **Qualidade de Código**: Redução de complexidade cognitiva, linting com SonarQube
- ✅ **APIs Integradas**: Piston API para execução remota de código C e Bash

### Funcionalidades Técnicas
- Execução remota via Piston API (fallback para simulação local)
- Sistema de quizzes com validação automática
- Progresso persistido via localStorage
- Modo escuro/claro com detecção automática
- Design responsivo para mobile e desktop
