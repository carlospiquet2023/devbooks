# DevBooks - Plataforma de Aprendizado de C

![DevBooks Logo](https://img.shields.io/badge/DevBooks-Learning%20Platform-blue?style=for-the-badge&logo=book)

Uma plataforma educacional interativa e gratuita para aprender a linguagem de programação C, desde conceitos básicos até níveis avançados de especialização.

## 📚 Sobre o Projeto

DevBooks é uma plataforma completa de aprendizado que oferece:
- **Conteúdo Progressivo**: Do básico ao avançado em 7 níveis
- **Interatividade**: Editores de código, simuladores e quizzes
- **Gamificação**: Sistema de progresso e conquistas
- **Integração com APIs**: Exemplos reais do GitHub e discussões no Stack Overflow
- **Design Responsivo**: Interface moderna com modo escuro

## 🚀 Funcionalidades

### 📖 Módulos de Aprendizado
1. **Fundamentos de C** - Sintaxe básica, variáveis, estruturas de controle
2. **Sistemas Operacionais** - Interação com SO, processos, threads
3. **C++ e Orientação a Objetos** - Evolução para C++, classes, herança
4. **Algoritmos e Estruturas de Dados** - Complexidade, algoritmos eficientes
5. **Produção e Desenvolvimento** - Boas práticas, versionamento, deployment
6.. **Especialização e Carreira** - Áreas avançadas, certificações, networking
7. **Nível Mestre** - Tópicos avançados, pesquisa, contribuição open source

### 🛠️ Ferramentas Interativas
- **Editor de Código**: Com realce de sintaxe e modo C
- **Simulador printf**: Teste saídas formatadas
- **Quizzes Avaliativos**: Teste seu conhecimento
- **Sistema de Progresso**: Acompanhe seu avanço
- **Integrações**: GitHub API e Stack Overflow

### 🎨 Interface
- Design moderno com Tailwind CSS
- Modo escuro/claro
- Totalmente responsivo
- Navegação intuitiva

## 🏗️ Tecnologias Utilizadas

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
- **Editor**: Ace Editor para edição de código
- **APIs**: GitHub API, Stack Overflow API
- **Armazenamento**: localStorage para progresso e preferências
- **Responsividade**: Mobile-first design

## 📋 Pré-requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexão com internet para funcionalidades de API
- JavaScript habilitado

## 🚀 Como Usar

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/carlospiquet2023/devbooks.git
   cd devbooks
   ```

2. **Abra no navegador**:
   - Abra o arquivo `index.html` em seu navegador
   - Ou use um servidor local (recomendado para melhor experiência)

3. **Comece aprendendo**:
   - Navegue pelas páginas usando os cards na página inicial
   - Leia o conteúdo, pratique nos editores
   - Faça os quizzes para testar seu conhecimento
   - Acompanhe seu progresso no dashboard

## 📁 Estrutura do Projeto

```
devbooks/
├── index.html          # Página inicial com dashboard
├── segundo.html        # Sistemas Operacionais
├── terceiro.html       # C++ e Orientação a Objetos
├── quarto.html         # Algoritmos e Estruturas
├── quinto.html         # Produção e Desenvolvimento
├── sexto.html          # Especialização e Carreira
├── setimo.html         # Nível Mestre
├── termos.html         # Termos de Uso
└── lgpd.html          # Política de Privacidade (LGPD)
```
