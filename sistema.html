Calculadora Simples

Use esta calculadora básica para operações aritméticas. A lógica pode ser implementada em C, COBOL, etc.

Como foi implementado no site:

  • HTML: Define a estrutura da calculadora (display e botões). Ex.: <input id="display"> para o visor e <button onclick="appendToDisplay('1')">1</button> para os botões.
  • CSS: Estiliza a aparência (tamanhos, cores, layout). Ex.: Botões de 50x50px, display alinhado à direita.

Linguagem C

C é uma linguagem de baixo nível, ideal para sistemas operacionais e aplicações eficientes.

Como foi usado no mini sistema:

O exemplo abaixo mostra como implementar a lógica da calculadora (operações aritméticas) em C. Lê entrada do usuário (dois números e operador) e calcula o resultado, demonstrando como linguagens de sistema podem lidar com cálculos simples. Para integrar no site, copie o código, compile e execute no terminal.

Exemplo: Calculadora Simples

#include <stdio.h>

int main() {
    double a, b, result;
    char op;
    printf("Digite dois números e um operador (+, -, *, /): ");
    scanf("%lf %c %lf", &a, &op, &b);
    switch(op) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/': if(b != 0) result = a / b; else { printf("Erro: divisão por zero\n"); return 1; } break;
        default: printf("Operador inválido\n"); return 1;
    }
    printf("Resultado: %.2f\n", result);
    return 0;
}

Para executar: Compile com gcc calc.c -o calc e rode ./calc.

Linguagem COBOL

COBOL é usado em sistemas empresariais e financeiros, com sintaxe verbosa.

Como foi usado no mini sistema:

O exemplo abaixo replica a lógica da calculadora em COBOL, mostrando como linguagens empresariais podem processar cálculos. Usa estruturas como EVALUATE para operadores e COMPUTE para operações, contrastando com a versão web. Para usar, compile e execute separadamente.

Exemplo: Calculadora Simples

IDENTIFICATION DIVISION.
PROGRAM-ID. CALCULATOR.

DATA DIVISION.
WORKING-STORAGE SECTION.
01 A PIC 9(5)V99.
01 B PIC 9(5)V99.
01 RESULT PIC 9(5)V99.
01 OP PIC X.

PROCEDURE DIVISION.
    DISPLAY "Digite dois números e um operador (+, -, *, /):".
    ACCEPT A.
    ACCEPT OP.
    ACCEPT B.
    EVALUATE OP
        WHEN '+'
            COMPUTE RESULT = A + B
        WHEN '-'
            COMPUTE RESULT = A - B
        WHEN '*'
            COMPUTE RESULT = A * B
        WHEN '/'
            IF B NOT = 0
                COMPUTE RESULT = A / B
            ELSE
                DISPLAY "Erro: divisão por zero"
                STOP RUN
        WHEN OTHER
            DISPLAY "Operador inválido"
            STOP RUN
    END-EVALUATE.
    DISPLAY "Resultado: " RESULT.
    STOP RUN.

Para executar: Use um compilador COBOL como OpenCOBOL (cobc -x calc.cob).
